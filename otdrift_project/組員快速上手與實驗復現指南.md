## 📌 一、專案核心價值與創新摘要（給組員 1 分鐘掌握全貌）

傳統 IT 資安工具（如 Tripwire、GitOps 比對）或龐大的深度學習模型（如 USENIX Security 2025 的 *GeCos*）無法直接部署在資源受限、即時性要求極高的工控現場邊緣端（如工業交換機、OpenWrt 工控閘道器）。

本專案 `otdrift` 針對 **ISA-95 / Purdue Model 第 1.5 層（邊緣安全閘道器）**，實現了：
1. **加權樹狀語意編輯距離 ($D_{\text{W-STED}}$) 與歸一化飄移指數 ($\text{NDI}$)**：
   - 依據工控層級給予不同權重：物理製程安全層（權重 3.0）> 邊緣網關防護（2.0）> 管理介面（1.5）> 基礎網路（1.0）。
   - 將組態差異轉化為數學上可精確衡量的語意距離與工控風險評分（0~100 分）。
2. **零外部依賴原生邊緣引擎 (`openwrt/otdrift_edge.py`)**：
   - 擺脫 `deepdiff`、`pymodbus`、`rich` 等龐大套件，僅需 Python 標準函式庫即可在 OpenWrt 路由器上原生秒級執行。
3. **雙軌動態感知（Dual-Track Auditing）**：
   - **北向/閘道層**：即時解析 OpenWrt UCI 防火牆與網路邊界設定 (`/etc/config/firewall`)。
   - **南向/現場層**：透過底層 Raw Socket 直接探測 PLC Modbus TCP 保持暫存器（Holding Registers）之物理不變量。
4. **MITRE ATT&CK for ICS 對齊與主動處置手冊 (Playbook)**：
   - 偵測到邊界弱化自動映射至 `T0855 (Unauthorized Command Message)`。
   - 偵測到設備參數遭竄改自動映射至 `T0839 (Modify Parameter)`。
   - 提供現場復原指令，並支援 `--auto-block` 動態注入 iptables 邊緣阻斷。

## 🚀 三、3 分鐘復現真實 OpenWrt 工控攻防實驗（Ubuntu VM / Docker）

我們已經在虛擬機中建立真實的工業網路測試環境：
- 隔離網段：`ot_carrier_net` (`172.28.0.0/16`)
- 閘道節點：OpenWrt Industrial Gateway (`172.28.0.2`)
- 實體工控 PLC：OpenPLC v3 (`172.28.0.50:502`)

### 步驟 1：啟動環境與進入 OpenWrt
在 Ubuntu 終端機中：
```bash
cd ~/專題
# 啟動容器群
docker compose -f docker/docker-compose.yml up -d

# 進入 OpenWrt 工控閘道器終端機
docker exec -it ot_openwrt_gateway sh
```

### 步驟 2：在 OpenWrt 中建立黃金標準基線 (Baseline)
在 OpenWrt 的提示字元 `/ # ` 執行：
```sh
# 匯出當前正常組態（防火牆標準 REJECT + PLC 基準值）
python3 /root/otdrift_edge.py --export-baseline /root/golden_baseline.json --modbus-host 172.28.0.50 --modbus-port 502

# 驗證基線（此時應為 0 飄移，整片綠字！）
python3 /root/otdrift_edge.py -b /root/golden_baseline.json --live --modbus-host 172.28.0.50 --modbus-port 502
```

### 步驟 3：發動複合工控模擬攻擊
在 OpenWrt 終端機依序輸入攻擊指令：
```sh
# 攻擊 1：弱化閘道防火牆轉發政策（將 REJECT 改為放行 ACCEPT）
uci set firewall.@defaults[0].forward='ACCEPT'
uci commit firewall

# 攻擊 2：下達 Modbus FC 06 指令，將 PLC 幫浦切斷壓力竄改為超壓 140 psi
python3 -c "import socket; s=socket.socket(); s.connect(('172.28.0.50', 502)); s.sendall(bytes([0,1,0,0,0,6,1,6,0,0,0,140])); s.recv(1024); s.close(); print('[!] 已向 PLC 寫入超壓設定值：140 psi')"
```

### 步驟 4：執行即時邊緣審計（見證震撼告警！）
```sh
python3 /root/otdrift_edge.py -b /root/golden_baseline.json --live --modbus-host 172.28.0.50 --modbus-port 502
```
**終端機將跳出雙重 CRITICAL 告警：**
- `firewall.defaults.defaults_0.forward` (REJECT -> ACCEPT, 距離 2.00, **T0855**)
- `process_registers.pump_cutoff_pressure_psi` (0 -> 140, 距離 3.00, **T0839**)
- W-STED 距離達 **5.00**，風險評分高達 **86 / 100**，並輸出即時處置對策！

### 步驟 5：一鍵閉環復原
```sh
# 1. 還原防火牆
uci set firewall.@defaults[0].forward='REJECT'
uci commit firewall

# 2. 還原 PLC 壓力為 0
python3 -c "import socket; s=socket.socket(); s.connect(('172.28.0.50', 502)); s.sendall(bytes([0,1,0,0,0,6,1,6,0,0,0,0])); s.recv(1024); s.close(); print('[+] PLC 數值已還原')"

# 3. 再次複查，確認回到 0 飄移安全狀態 (全綠字)
python3 /root/otdrift_edge.py -b /root/golden_baseline.json --live --modbus-host 172.28.0.50 --modbus-port 502
```

## 📂 四、專案原始碼目錄架構

├── otdrift/                    # otdrift 核心 Python 函式庫
